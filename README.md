# Telegram Bot S

## Sobre o projeto

Este projeto tem como objetivo desenvolver uma plataforma backend utilizando Java e Spring Boot, integrando diferentes tecnologias e conceitos utilizados no desenvolvimento de sistemas reais.

A aplicação iniciou como um bot do Telegram, evoluindo para uma API capaz de gerenciar dados, regras de negócio e integrações externas.

O objetivo é construir uma base escalável aplicando boas práticas de arquitetura, organização de código e desenvolvimento backend.
